[b]Who Downloaded Attachment 1.1.15[/b]

Мод показывает список пользователей, скачавших вложение: имя, время и IP-адрес.

[b]Совместимость[/b]
[list]
[li]SMF 2.1.x (PHP 7.1+)[/li]
[/list]

[b]После установки[/b]

Включите право [b]Просмотр списка скачавших вложение[/b] ([b]show_download_list[/b]) для нужных групп пользователей.

[b]Настройки[/b]
[list]
[li]Время кэширования списка (по умолчанию: 60 секунд).[/li]
[li]Максимальный возраст записей (0 = все).[/li]
[li]Максимальное число строк (по умолчанию: 1000).[/li]
[li]Показ IP-адресов только администраторам.[/li]
[/list]

Скачивания гостей не записываются. История начинает собираться после установки мода.

Полная документация и релизы: [url=https://github.com/realdigger/SMF-Who-Downloaded-Attachment]GitHub[/url]
