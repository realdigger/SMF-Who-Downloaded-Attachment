[b]Who Downloaded Attachment 1.1.15[/b]

Shows members who downloaded an attachment: name, time and IP address.

[b]Compatibility[/b]
[list]
[li]SMF 2.0.19+ (PHP 5.4+)[/li]
[li]SMF 2.1.x (PHP 7.1+)[/li]
[/list]

[b]After installation[/b]

Enable [b]View attachment download list[/b] ([b]show_download_list[/b]) for the required member groups.

[b]Settings[/b]
[list]
[li]Cache lifetime for the list (default: 60 seconds).[/li]
[li]Maximum age of records (0 = all).[/li]
[li]Maximum number of rows (default: 1000).[/li]
[li]Show IP addresses to administrators only.[/li]
[/list]

Guest downloads are not logged. The history begins accumulating after installation.

Full documentation and releases: [url=https://github.com/realdigger/SMF-Who-Downloaded-Attachment]GitHub[/url]
